Design Studio

The Wizard creates a new, unique design from an existing template. The initial design is not changed.

  1. Select template and new technical names.
  2. Page distribution, menu form, content width and footer.
  3. Determine branding, logo, colors and typography.
  4. Create design, check it and view it in a new tab.

For extensive visual changes can be taken from the design list dbxKi-Order to be generated as ZIP and the result checked before loading.
