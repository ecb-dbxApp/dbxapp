What is this module for?

dbxUser_admin serves to manage all user accounts and groups. This way you control who is allowed to register and what role someone has in the system.

What can you do with it?

  • Create new users and edit existing ones
  • Defining Groups and Roles
  • Control access rights over group membership
  • Search and filter user lists
Tip: Work with groups instead of individual rights – this makes care clearer and safer.
