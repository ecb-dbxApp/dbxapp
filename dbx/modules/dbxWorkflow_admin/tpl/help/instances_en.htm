What does this overview show?

Every start in dbxWorkflow Creates its own instance. The list shows workflow key, goal, status, current step, progress, and the last message.

Understanding status

running → paused → running → finished └──────────→ canceled The error
  • Running: the next applicable step can be processed.
  • Stopped: values are retained; the passage can be continued.
  • Cancelled: no further processing without a conscious restart.
  • Finished: all mandatory steps and the finish logic were successful.
  • Error: Check notification and subject module.

Search for errors

  1. Open instance over the action.
  2. Read last message and current step.
  3. In the case of blocked steps, check prerequisite and expected result value.
  4. For module actions, check the technical data set and the binding used.
  5. For external actions before a restart, check the provider status first.
