Creación de flujo de trabajo en el diseñador

El diseñador visual describe un objetivo profesional y todo lo que se necesita para ello. La definición técnica JSON se genera automáticamente durante el almacenamiento; la vista previa técnica está destinada sólo para el control.

1. Establecimiento de un objetivo

  • Clave de flujo de trabajo: claves técnicas estables, por ejemplo project_offerNo más renombramiento después de comienzos productivos.
  • Nombre: título comprensible de la expiración.
  • Objetivo: resultado concreto, que debe estar disponible después de los estados financieros.
  • Descripción: Explique brevemente cuándo se utiliza el flujo de trabajo.
  • Activo: Sólo se pueden reiniciar las definiciones activadas.

2. Medidas de construcción

Haga clic en el módulo o arrastrelo en la secuencia, abra los detalles y luego tráigalo en el orden correcto por mango.

  • Entrada: Capturar, seleccionar o reinvertir valor.
  • Action: abrir un formulario técnico existente y confirmar la terminación.
  • Prueba: datos de control; con Pruebas automáticas sólo independientemente si el módulo sujeto puede ofrecer un valor seguro.
  • Decisión: definir al menos dos resultados a los que los pasos posteriores pueden ramificarse.

3. Obligación, procesamiento y ramificación

  1. Asignar un identificador único y clave interna para cada paso.
  2. Seleccione ediciones permitidas: forma, selección, nueva instalación y/o forma de módulo.
  3. Los pasos obligatorios deben proporcionar un valor válido; los pasos opcionales se pueden saltar deliberadamente.
  4. Para una rama abajo Condiciones un paso anterior y opcionalmente bajo Sólo para resultados Indica su valor.
  5. Valores de selección línea por línea wert=Beschriftung Entra.
Lanzamiento (llama: aprobación) - aprobado → orden de ejecución ─ Cambios del proceso → consultas

4. Conexión del módulo y pruebas

Para utilizar selecciones DD, formularios especializados o promociones de acabado, bajo Información ampliada a referencia como dbxContact|contact_reply Entra. La unión asociada se separa bajo Cargos de módulos mantenido.

  1. Guardar y resolver todos los mensajes de diseño.
  2. Activar la definición.
  3. Iniciar una nueva prueba de la lista de flujo de trabajo.
  4. Valores obligatorios completos de prueba, ramas, acciones de módulos y terminación.

Nota: Las instancias en curso mantienen el estado de definición de su comienzo. Una corrección en el diseñador afecta al próximo comienzo.
