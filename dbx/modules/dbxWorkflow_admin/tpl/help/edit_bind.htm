Binding bearbeiten

Das Binding beschreibt die technische Verbindung zwischen einer Workflow-Definition und einem vorhandenen Fachmodul. Es wird als JSON gespeichert und über modul|bind_key referenziert.

Mit dem Generator beginnen

  1. Modulname eintragen.
  2. Eine DD des Moduls auswählen.
  3. Grundgerüst erzeugen und anschließend das JSON prüfen.
  4. Eindeutigen Bind Key, verständlichen Titel und Aktiv-Status speichern.

Wichtige Bereiche

record → Fach-DD und Need mit der Datensatz-ID needs[] → Auswahl, Feldoptionen, Vorbelegung und Kontext je Schritt finish[]→ erlaubte Fachänderung und optionale Folgeaktion
Vereinfachtes Beispiel: 
{
  "record": {"dd": "dbxContact|contactRequest", "id_need": "contact_request"},
  "needs": {
    "contact_request": {"type": "dd_select", "label": "{subject}"},
    "status": {"type": "dd_field_options", "field": "status"}
  },
  "finish": {
    "type": "dd_update",
    "map": {"status": "status"}
  }
}

Vor dem Aktivieren prüfen

  • Existieren DD, Feldnamen und Templates?
  • Zeigt id_need auf einen Schritt der Workflow-Definition?
  • Sind Auswahlfilter eng genug und Datensatzrechte berücksichtigt?
  • Ändert finish nur die vorgesehenen Felder?
  • Wird Mail oder eine externe Aktion erst nach erfolgreicher Fachänderung ausgeführt?
