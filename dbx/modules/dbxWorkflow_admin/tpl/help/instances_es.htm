¿Qué muestra esta visión general?

Cada comienzo en dbxWorkflow Crea su propia instancia. La lista muestra el flujo de trabajo clave, objetivo, estado, paso actual, progreso y el último mensaje.

Comprensión de la situación

running → pausado → running → terminado - Se canceló El error
  • Corriendo: el siguiente paso aplicable puede ser procesado.
  • Detenido: se mantienen los valores; el pasaje puede continuar.
  • Cancelado: no más procesamiento sin un reinicio consciente.
  • Terminado: todos los pasos obligatorios y la lógica final fueron exitosos.
  • Error: Compruebe la notificación y el módulo de sujeto.

Buscar errores

  1. Abrir instancia sobre la acción.
  2. Lea el último mensaje y el paso actual.
  3. En el caso de pasos bloqueados, comprobar el requisito previo y el valor de resultado esperado.
  4. Para las acciones del módulo, compruebe el conjunto de datos técnicos y el enlace utilizado.
  5. Para acciones externas antes de reiniciar, consulte primero el estado del proveedor.

Estado de definición: Nuevas instancias guardan una instantánea al inicio. Enmiendas a dbxWorkflow_admin Por lo tanto, no cambie los procesos ya iniciados. Los casos más antiguos sin instantánea siguen utilizando la definición actual por razones de compatibilidad.
