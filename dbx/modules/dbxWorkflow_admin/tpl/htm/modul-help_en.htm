What is this module for?

dbxWorkflow_admin is the mandatory source for executable workflow definitions. Here, administrators set goals, steps, exams, decisions and optional subject module bindings.

Define Objective → Arrange Steps → Control Examination → Optionally Assign Binding → Activate → In dbxWorkflow Test test

Recommended approach

  1. Create workflow with a clear key and understandable goal.
  2. Build input, actions, exams and decisions in the visual designer.
  3. Control of mandatory information and branches.
  4. Create a module binding for DD/trayer accesses and bind_ref Assignment.
  5. Activate and fully test via the start action.

New instances receive a definition snapshot at start. Changes to a definition thus apply to new runs, not retroactively to already running ones.
