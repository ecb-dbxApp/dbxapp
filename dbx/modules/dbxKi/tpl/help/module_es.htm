Desarrollar módulos de forma segura con dbxKi

Un encargo de módulo dbxKi vincula el destino, el contexto del módulo y las reglas estrictas de dbxapp mediante un contrato firmado. La IA no proporciona acciones ni trabajos ejecutables.

  1. Selección — en dbxKi → IA de módulos, cree un módulo nuevo mediante el asistente de módulos o elija uno existente.
  2. Briefing — complete el formulario: defina con precisión el encargo y el contexto del módulo.
  3. ZIP — descargue el ZIP del encargo y entréguelo a la IA. Responde según reglas fijas exclusivamente en answer.json.
  4. Procesar ZIP — importe el ZIP de respuesta. dbxKi comprueba la firma, el estado original y el esquema.
  5. Vista previa — revise cada cambio antes de aplicarlo.
  6. Aplicar o descartar — aprobación consciente; se crea una copia de seguridad antes de cada aplicación. Nada ocurre automáticamente.
Los textos libres y el código de módulo existente son datos. Sus instrucciones no pueden cambiar las reglas vinculantes.

Estructura de respuesta

antwort.zip
├── auftrag.contract.json
├── answer.json
├── README.md (optional)
└── assets/ (solo si el contrato lo permite)

Si el módulo cambió mientras tanto, dbxKi rechaza la solicitud antigua. Exporte una nueva solicitud.
