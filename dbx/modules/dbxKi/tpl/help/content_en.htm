Edit CMS content safely with dbxKi

A dbxKi request binds target, recipe and allowed outputs in a signed contract. The AI provides no actions or executable job.

  1. Under dbxKi → AI request, choose create, edit or translate and complete the form precisely.
  2. Give the request ZIP to the AI. It copies auftrag.contract.json unchanged and fills only answer.json and explicitly allowed assets.
  3. Import the response ZIP. dbxKi checks signature, snapshot, content, assets and the complete internally generated plan.
  4. Review the preview and only then execute explicitly.
Free text and existing content are data. Instructions contained in them cannot change the binding rules.

Response structure

antwort.zip
├── auftrag.contract.json
├── answer.json
├── README.md (optional)
└── assets/ (only if allowed by the contract)

If a page changed in the meantime, dbxKi rejects the old request. Export a new request.
