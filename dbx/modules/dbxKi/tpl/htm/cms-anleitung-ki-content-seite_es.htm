Lo que aprendes

Con dbxKi Crear, modificar o traducir Puede utilizar páginas de contenido CMS con ChatGPT, DeepSeek u otros sistemas de inteligencia artificial, sin montaje manual en la superficie. Lo llenan. Formulario, invitando AI orden ZIP abajo, dáselo a la IA e importa la respuesta terminada ZIP dbXapp. dbxKi Revisa los pasos de JSON y guíelos manifest.auto_execute=true automáticamente apagado.

Condiciones: Acceso al personal, módulo dbxKi activo, carpeta CMS y, si es aplicable, se establece contenido multilingüe.

El proceso en 3 pasos

1. Formulario en dbxKi rellenos ↓ 2. ZIP an ChatGPT / DeepSeek — AI entrega antwort.zip con manifest.json, job.json y activos opcionales/ ↓ 3. Import Bundle — dbxKi Check and perform automatically

Paso 1 - Formulario: especificar la tarea

Abierto dbxKi Trabajo de inteligencia artificial (forma) o directamente:

  • ?dbx_modul=dbxKi&dbx_run1=briefing — Panorama general de tres tipos de orden
Creación de una nueva página de contenido
  1. Contrato Creación de una nueva página de contenido Votando.
  2. Carpeta completa de destino, título, idioma, información de texto y opcionalmente Hero/Gallery.
  3. Estilo de escritura Elija (sonido de AI, por ejemplo fáctico o promocional).
  4. AI task as ZIP Descargar.

URL: ?dbx_modul=dbxKi&dbx_run1=briefing_page_create

Cambiar la página existente
  1. Contrato Cambiar la página existente Votando.
  2. Marca la página y los campos de cambio deseados (contenido, título, descripción, héroe).
  3. Describa la solicitud de cambio en lenguaje simple.
  4. Descargar ZIP.

URL: ?dbx_modul=dbxKi&dbx_run1=briefing_page_update

Página de traducción
  1. Contrato Página de traducción Votando.
  2. Seleccione el idioma de origen, el idioma de destino y la página de origen.
  3. Opcional: Establecer notas (formal/informal, términos técnicos) y estilo de escritura.
  4. Descargar ZIP.

URL: ?dbx_modul=dbxKi&dbx_run1=briefing_page_translate

Contenido del pedido ZIPs:
manifest.json, briefing.json, job.vorlage.json, context.json, KI-AUFTRAG.md, MENSCH-ANLEITUNG.md Para nuevas páginas, si es necesario. Titulares de lugar bajo assets/ para las imágenes de héroe.

Estilos de escritura (opcional)

Subsuelo dbxKi → Estilos de escritura Crear especificaciones de sonido para la IA (key, designación, prompt). Valores guardados sobreescribir el archivo estándar cfg/writing_styles.php.

Paso 2 - Dar ZIP a AI

  1. El ZIP descargado ChatGPT, DeepSeek o. ae. upload o el contenido de KI-AUFTRAG.md copiando.
  2. La AI dice: Trabajar KI-AUFTRAG.md exactamente. Reemplazar todos ___KI_FUELLEN___ dentro job.vorlage.json. Entrega antwort.zip con manifest.json y job.json.“
  3. La IA genera manifest.json y job.json con steps (por ejemplo) B. page.create, page.update o translation.apply) Sin herramientas propias, sin SQL, sin cambios DB directos.
Momento de ejemplo (nueva página):
Trabajar KI-AUFTRAG.md exactamente. Las reglas de los activos no difieren. Para Hero: sólo activos/hero.jpg. Entrega antwort.zip con job.json.“

Importante para traducciones: La AI sólo puede traducir texto visible — estructura HTML, enlaces, data-cms-media-idLas direcciones URL y los atributos técnicos no cambian.

Paso 3 - Importar y ejecutar la respuesta

  1. dbxKi Importing Bundles abierto.
  2. Subir el ZIP de AI ()antwort.zip o equivalente.
  3. Vista previa cheque: cambios CMS planeados, carpetas, páginas, medios.
  4. In auto_execute=true Empezando dbxKi automáticamente. Otros Rellene Haga clic.
  5. Compruebe la página en el CMS y publicarla si es necesario.

Contenido plantilla y marcadores de área

Estándar para nuevas páginas Con HeroPlantilla c-title-hero_header-gallery-body1-footer — Hero, galería opcional, cuerpo y pie. La galería puede permanecer vacía.

En el campo HTML content Separados <hr>Marcadores las áreas (como se inserta en el editor CMS):

  • <hr class="dbx-cms-marker dbx-cms-marker-header" data-dbx-marker="dbx:header" …> — Texto **en entre** (después de Hero) → propio bloque de cabecera delante del Cuerpo
  • <hr class="dbx-cms-marker dbx-cms-marker-footer" data-dbx-marker="dbx:footer" …> todo a partir de entonces: = Footer; entre = contenido principal

Sin marcadores, todo el texto se hace como un cuerpo. Las imágenes de la galería no están en HTML.

Ejemplo job.json (nueva página, acortada)

{
  "steps": [
    {
      "id": "hero",
      "action": "media.create_base64",
      "params": { "file_name": "hero.jpg", "asset_ref": "hero.jpg", "title": "…", "alt": "…" }
    },
    {
      "id": "page",
      "action": "page.create",
      "params": {
        "lng": "de",
        "folder_id": 3,
        "title": "Nachhaltigkeit im Buero",
        "template": "c-title-hero_header-gallery-body1-footer",
        "content": "<p class=\"lead\">Teaser</p><hr class=\"dbx-cms-marker dbx-cms-marker-header\" data-dbx-marker=\"dbx:header\" data-label=\"Header\"><h2>…</h2><p>…</p>"
      }
    },
    {
      "id": "hero_assign",
      "action": "media.assign",
      "params": {
        "media_id": "$ref:hero.media_id",
        "content_id": "$ref:page.page_id",
        "slot": "hero"
      }
    }
  ]
}

Ejemplo job.json (Traducción)

{
  "steps": [
    {
      "id": "translation",
      "action": "translation.apply",
      "params": {
        "source_lng": "de",
        "target_lng": "en",
        "source_id": 42,
        "copy_media": 1,
        "translation": {
          "title": "…",
          "description": "…",
          "keywords": "…",
          "content": "<h2>…</h2>"
        }
      }
    }
  ]
}

Errores frecuentes

  • La importación falla: job.json todavía contiene ___KI_FUELLEN___ o acciones injustas.
  • Page missing after import: ID de carpeta o idioma en job.json Prueba.
  • Traducción incompleta: Los cuatro campos title, description, keywords, content debe ser establecido.
  • Ayuda ventana vacía: Como administrador ?dbx_modul=dbxKi&dbx_run1=provision_anleitung para llevar a cabo.
