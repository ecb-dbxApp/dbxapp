Was Sie lernen

Mit dbxKi erstellen, aendern oder uebersetzen Sie CMS-Content-Seiten mit ChatGPT, DeepSeek oder anderen KI-Systemen — ohne manuelles HTML-Zusammenbauen in der Oberflaeche. Sie fuellen ein Formular, laden ein KI-Auftrags-ZIP herunter, geben es der KI und importieren die fertige Antwort-ZIP wieder in dbXapp. dbxKi prueft die JSON-Steps und fuehrt sie bei manifest.auto_execute=true automatisch aus.

Voraussetzungen: Admin-Zugang, Modul dbxKi aktiv, CMS-Ordner und ggf. mehrsprachige Inhalte eingerichtet.

Der Ablauf in 3 Schritten

1. Formular in dbxKi ausfuellen ↓ 2. ZIP an ChatGPT / DeepSeek — KI liefert antwort.zip mit manifest.json, job.json und optional assets/ ↓ 3. Bundle importieren — dbxKi prueft und fuehrt automatisch aus

Schritt 1 — Formular: Auftrag spezifizieren

Oeffnen Sie dbxKi → KI-Auftrag (Formular) oder direkt:

  • ?dbx_modul=dbxKi&dbx_run1=briefing — Uebersicht mit drei Auftragstypen
Neue Content-Seite anlegen
  1. Auftrag Neue Content-Seite anlegen waehlen.
  2. Zielordner, Titel, Sprache, Text-Briefing und optional Hero/Galerie ausfuellen.
  3. Schreibstil waehlen (Ton der KI, z. B. sachlich oder werblich).
  4. KI-Auftrag als ZIP herunterladen.

URL: ?dbx_modul=dbxKi&dbx_run1=briefing_page_create

Bestehende Seite aendern
  1. Auftrag Bestehende Seite aendern waehlen.
  2. Seite und gewuenschte Aenderungsfelder (Inhalt, Titel, Beschreibung, Hero) markieren.
  3. Aenderungswunsch in Klartext beschreiben.
  4. ZIP herunterladen.

URL: ?dbx_modul=dbxKi&dbx_run1=briefing_page_update

Seite uebersetzen
  1. Auftrag Seite uebersetzen waehlen.
  2. Quellsprache, Zielsprache und Quellseite waehlen.
  3. Optional: Hinweise (formell/informell, Fachbegriffe) und Schreibstil setzen.
  4. ZIP herunterladen.

URL: ?dbx_modul=dbxKi&dbx_run1=briefing_page_translate

Inhalt der Auftrags-ZIP:
manifest.json, briefing.json, job.vorlage.json, context.json, KI-AUFTRAG.md, MENSCH-ANLEITUNG.md — bei neuen Seiten ggf. Platzhalter unter assets/ fuer Hero-Bilder.

Schreibstile pflegen (optional)

Unter dbxKi → Schreibstile legen Sie Ton-Vorgaben fuer die KI an (Schluessel, Bezeichnung, Prompt). Gespeicherte Werte ueberschreiben die Standarddatei cfg/writing_styles.php.

Schritt 2 — ZIP an die KI geben

  1. Die heruntergeladene ZIP bei ChatGPT, DeepSeek o. ae. hochladen oder den Inhalt von KI-AUFTRAG.md kopieren.
  2. Der KI sagen: „Arbeite KI-AUFTRAG.md exakt ab. Ersetze alle ___KI_FUELLEN___ in job.vorlage.json. Liefere antwort.zip mit manifest.json und job.json.“
  3. Die KI erzeugt manifest.json und job.json mit steps (z. B. page.create, page.update oder translation.apply). Keine eigenen Tools, kein SQL, keine direkten DB-Aenderungen.
Beispiel-Prompt (neue Seite):
„Arbeite KI-AUFTRAG.md exakt ab. Assets-Regeln nicht abweichen. Bei Hero: nur assets/hero.jpg. Liefere antwort.zip mit job.json.“

Wichtig fuer Uebersetzungen: Die KI darf nur sichtbaren Text uebersetzen — HTML-Struktur, Links, data-cms-media-id, URLs und technische Attribute bleiben unveraendert.

Schritt 3 — Antwort importieren und ausfuehren

  1. dbxKi → Bundle importieren oeffnen.
  2. Die ZIP der KI hochladen (antwort.zip oder gleichwertig).
  3. Vorschau pruefen: geplante CMS-Aenderungen, Ordner, Seiten, Medien.
  4. Bei auto_execute=true startet dbxKi automatisch. Sonst Ausfuehren klicken.
  5. Seite im CMS kontrollieren und bei Bedarf veroeffentlichen.

Content-Template und Bereichs-Marker

Standard fuer neue Seiten mit Hero: Template c-title-hero_header-gallery-body1-footer — Hero, optionale Gallery, Body und Footer. Die Gallery darf leer bleiben.

Im HTML-Feld content trennen <hr>-Marker die Bereiche (wie im CMS-Editor eingefuegt):

  • <hr class="dbx-cms-marker dbx-cms-marker-header" data-dbx-marker="dbx:header" …> — Text **dazwischen** (nach Hero) → eigener Header-Block vor Body
  • <hr class="dbx-cms-marker dbx-cms-marker-footer" data-dbx-marker="dbx:footer" …> — alles danach = Footer; dazwischen = Hauptinhalt

Ohne Marker wird der gesamte Text als Body gerendert. Gallery-Bilder gehoeren nicht ins HTML.

Beispiel job.json (neue Seite, gekuerzt)

{
  "steps": [
    {
      "id": "hero",
      "action": "media.create_base64",
      "params": { "file_name": "hero.jpg", "asset_ref": "hero.jpg", "title": "…", "alt": "…" }
    },
    {
      "id": "page",
      "action": "page.create",
      "params": {
        "lng": "de",
        "folder_id": 3,
        "title": "Nachhaltigkeit im Buero",
        "template": "c-title-hero_header-gallery-body1-footer",
        "content": "<p class=\"lead\">Teaser</p><hr class=\"dbx-cms-marker dbx-cms-marker-header\" data-dbx-marker=\"dbx:header\" data-label=\"Header\"><h2>…</h2><p>…</p>"
      }
    },
    {
      "id": "hero_assign",
      "action": "media.assign",
      "params": {
        "media_id": "$ref:hero.media_id",
        "content_id": "$ref:page.page_id",
        "slot": "hero"
      }
    }
  ]
}

Beispiel job.json (Uebersetzung)

{
  "steps": [
    {
      "id": "translation",
      "action": "translation.apply",
      "params": {
        "source_lng": "de",
        "target_lng": "en",
        "source_id": 42,
        "copy_media": 1,
        "translation": {
          "title": "…",
          "description": "…",
          "keywords": "…",
          "content": "<h2>…</h2>"
        }
      }
    }
  ]
}

Haeufige Fehler

  • Import schlaegt fehl: job.json enthaelt noch ___KI_FUELLEN___ oder ungueltige Aktionen.
  • Seite fehlt nach Import: Ordner-ID oder Sprache in job.json pruefen.
  • Uebersetzung unvollstaendig: Alle vier Felder title, description, keywords, content muessen gesetzt sein.
  • Hilfe-Fenster leer: Als Admin ?dbx_modul=dbxKi&dbx_run1=provision_anleitung ausfuehren.

Weiterfuehrend

  • KI-Auftrag-Hub: ?dbx_modul=dbxKi&dbx_run1=briefing
  • Bundle-Import: ?dbx_modul=dbxKi&dbx_run1=bundle
  • API-Beschreibung: ?dbx_modul=dbxKi&dbx_run1=api&action=system.describe
