Ein neues Content-Template anlegen

  1. Geben Sie einen Dateinamen ein, der mit c- beginnt.
  2. Verwenden Sie danach nur Buchstaben, Zahlen, Bindestriche und Unterstriche.
  3. Waehlen Sie Anlegen. Das Grundgeruest wird im Template-Ordner des Content-Moduls erzeugt.
  4. Oeffnen Sie das neue Template anschliessend im Editor und passen Sie die vorgesehenen Content-Bereiche an.
Der Name wird ohne Dateiendung eingegeben. Ein vorhandenes Template gleichen Namens darf nicht unbeabsichtigt ueberschrieben werden.
