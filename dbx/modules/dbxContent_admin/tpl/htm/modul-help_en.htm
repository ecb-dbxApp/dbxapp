What is this module for?

dbxContent_admin is the editorial CMS for pages, folders, media, navigation and language versions. The page editor is under ?dbx_modul=dbxContent_admin&dbx_run1=content&dbx_run2=edit reachable.

Buttons

  • Storage: stores page or folder; Alternative Strg+S.
  • Translation: Transmits the Master in selected languages.
  • Auto-Sync: reconnects manual language versions with the master.
  • Delete: Delete page or empty folder after confirmation.
  • Preview: shows the last stored status in the frontend.
  • New page: Create a page in the selected folder.
  • Duplicate page: copies the selected, stored page together with content, settings and media assignments. The permalink receives automatically -kopie, -kopie-2 etc.
  • Reloading: Update tree and editor from server.
  • New folder / Edit folders / Save folders / Delete folders: manages the tree structure and its rights.
  • Hero selection / Gallery selection / In-text selection: opens the media browser for the respective page area.
  • Save Hero / Store Gallery: saves the settings of the area.
  • Editor buttons: Source text, save everything, text style, counting, numbering, positioning, paragraph format, color, link, image, module, BootstrapComponent, video, dividing line, marker, undo, repeat and full screen edit the page content.

Input fields

  • Page: Title, unique permalink, content template, status, short description and visual content.
  • Hero: Template, medium, distance above, height, variant, sticky behavior and scroll level.
  • Gallery: Overflow representation and click behavior.
  • Folder: Name, assignment to the parent folder, content template and reading rights.
  • Other fields: Tree search, media filter, media folder, upload destination, file selection, external video URL and target languages in the translation dialog.
Duplication: Media files are not physically multiplied. The new site gets its own active media_usageassignments to the same media; Inline media are reassigned from the copied content.
Tip: Work in the master language first. Further languages can then be created and translated.
