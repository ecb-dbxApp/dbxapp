Idiomas dbXapp - Sinopsis

dbXapp distingue dos niveles:

  • Idiomas del sistema - qué idiomas están disponibles en el sitio web y en el administrador (por ejemplo, alemán, inglés, español).
  • Idiomas contenidos en CMS Cada página y cada carpeta existe Por idioma como un conjunto de datos separado, pero las versiones están vinculadas.

Esta ayuda explica ambos: la configuración de esta página Config y el trabajo diario en el contenido CMS.

Lenguaje maestro y otros idiomas

Master (e.g. DE*) . - Controla la estructura de carpetas y nuevas páginas " Loest “Transferido a otros idiomas” desde ─ Actualizaciones relativas a idiomas durante el almacenamiento (autosinc) Otros idiomas (EN, ES, ...) . - textos propios y enlaces por idioma - a menudo son "inactivos" en la comisión primero - Sí puede desviarse manualmente.

El enlace entre versiones de idiomas es Internos — Usted no tiene que mantener los mismos IDs de página en DE y EN. En el árbol usted reconoce el estado del Insignias de idioma (Presente, falta, coche, manual).

Trabajando en Contenido CMS

Entrada CMS: ?dbx_modul=dbxContent_admin&dbx_run1=cms

  • Fichas de idiomas arriba (DE*, EN, ES) — cambie el idioma de edición. La estrella muestra el lenguaje maestro.
  • Nueva página/carpeta en Master — después de guardar, el diálogo aparece si es necesario Traducir a otros idiomas.
  • Button "Translate" (Icono de idioma) — crea versiones de idiomas o actualiza la vista previa antes de transferir.
  • Botón "Auto-Sync" (Icono de enlace, sólo maestro) — devuelve idiomas separados a la ejecución automática.

Transferido a otros idiomas (provisión)

  1. La página o carpeta en la Idioma maestro Votando.
  2. Abrir diálogo (después de guardar o mediante el botón de traducción).
  3. Tick idiomas de destino, textos de verificación — Los proveedores de API generan avances.
  4. Takeover - Se crean nuevas versiones. Las páginas comienzan inactivasPara que puedas comprobar antes de la publicación.

In Carpetas Puede utilizar opcionalmente el Todo el subárbol incl. Páginas también transmitido. Las carpetas perdidas en los idiomas de destino se recrean automáticamente de la estructura maestra.

Auto-Sync — Save Master

Si usted ahorra en el idioma maestro, todos los idiomas relacionados con el estado auto actualizado en el fondo:

  • Textos (traducidos o copiados dependiendo del proveedor)
  • Estructura, configuración de plantillas, base permalink
  • Media connections (hero, galería, imágenes en el texto)

El Situación activa/inactiva el idioma objetivo se conserva – una página EN inactiva no se cambia de repente en vivo por sincronización maestro.

Fork — Si un idioma es permanecer único

Sálvalos en uno Idioma no maestro, el enlace se separa ()manual - Fork. Mensaje: Conexión de idiomas por separado (manualmente).

A partir de entonces, el maestro ya no adopta automáticamente este idioma. Esto tiene sentido para textos de marketing adaptados u otros permalinks.

Para unirse de nuevo: en el idioma maestro Auto-Sync Activar — el siguiente ahorro maestro entonces reescribirá el contenido de esclavos.

¿Qué proveedor para quién?

  • Instalación de cliente (estándar): copy - siempre funciona sin costo y sin servicio externo.
  • Sitio web pequeño con traducción automática: deepl con DeepL API Gratis (unos 500.000 caracteres por mes, 0 EUR).
  • Sitios más grandes / muchos textos: DeepL API Pro (pagado) o manualmente con copy mantener el diálogo.
  • OpenAI: Sólo si el operador deliberadamente soporta los costos de API — ChatGPT Plus/Pro no es acceso a API.
  • Google Traducir: In dbXapp no instalado. Sólo sobre custom + propio desarrollo posible.
Importante: ChatGPT en el navegador (Plus, Pro, ...) y el OpenAI API Dos productos separados. Una suscripción de chat no proporciona una clave de API y ningún crédito de API.

Página principal por idioma

El Página de inicio (maestra) es el ID de contenido de su página de inicio en el idioma principal (por ejemplo, página de inicio con ID 1).

  • Visitantes en el idioma principal ver esta página como una página web.
  • En EN/ES, el sistema busca la página enlazada (mejor contenido, lenguaje diferente).
  • Si falta una versión en idioma de la página principal, no hay página de inicio para este idioma.

Suprimir en varios idiomas

Eliminarlos de la Idioma maestro y hay varias versiones de idiomas, aparece un diálogo con las casillas de verificación:

  • auto-Las vistas son preestablecidas
  • manualVersiones sólo bajo petición
  • Los Permalinks se limpian por idioma

Medios de comunicación e idiomas

Los archivos multimedia son Idioma neutral (una imagen, un archivo). Están vinculados por página y idioma (héroe, galería, inline en el texto). En comisión y autosincronización, estos enlaces se copian en los idiomas de destino – no el archivo duplicado.

  2. Recarga página en el navegador con carga dura

Preguntas frecuentes

¿Por qué falta EN en el árbol?
La página fue creada sólo en el idioma principal. Guardar o “Translate” → ejecutar comisión para EN.

¿Por qué EN ya no está actualizada?
La EN fue almacenada manualmente (perro). Re-activar el auto-sinc en el idioma maestro o mantener conscientemente EN usted mismo.

¿La traducción comete errores?
Proveedor y clave API en esta página de configuración Admin by SysMsg Leyendo. Hasta la corrección, se copia el texto. Para DeepL: Compruebe la clave gratuita y la URL de API vacía. In OpenAI# Billing on plataforma.openai.com ¿Activo?

Tengo ChatGPT Pro - ¿Es suficiente?
No. ChatGPT Pro es sólo la suscripción de chat en el navegador. Para dbXapp Necesita una clave de API separada plataforma.openai.com (pagado después del uso) - o te quedas con copy DeepL Free.

¿Hay una traducción gratuita del coche para los clientes?
copy siempre es gratis. DeepL API Free (unos 500.000 caracteres/mes) es gratis, pero cada cliente necesita su propia cuenta: deepl.com/pro-api.

¿Puedo cambiar el idioma maestro?
Técnicamente sí — pero se refiere a la lógica y la página de inicio de CMS. Cambiar sólo sabiamente y luego comprobar la estructura/vínculos.

¿Qué significa el aviso de migración a continuación?
Estado interno de la base de datos para tablas multilingües, que no son pertinentes para uso cotidiano, sólo para apoyo/actualizaciones.
