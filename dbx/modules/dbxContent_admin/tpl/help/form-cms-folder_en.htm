Edit folders in the Content Tree

  1. Assign a clear, understandable folder name.
  2. With Assignment Determine the parent folder and thus the position in the content tree.
  3. The content template controls the presentation of the subordinate pages, as long as they inherit the value from the parent.
  4. Reading rights limit which user groups are allowed to see the folder and its content.
  5. Save the change with the button in the lower form area. The close icon discards inputs that are not yet stored.
An altered assignment moves the folder along with its underlying structure.
