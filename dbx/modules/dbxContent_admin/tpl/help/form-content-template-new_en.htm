Creating a new content template

  1. Enter a filename that has c- Begins.
  2. After that, use only letters, numbers, hyphens and underscores.
  3. Select Creation. The basic content is generated in the template folder of the content module.
  4. Then open the new template in the editor and adjust the intended content areas.
The name is entered without file extension. An existing template of the same name must not be inadvertently written over.
