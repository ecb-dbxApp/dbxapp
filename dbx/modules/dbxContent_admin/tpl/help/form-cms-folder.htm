Ordner im Content Tree bearbeiten

  1. Vergeben Sie einen eindeutigen, gut verstaendlichen Ordnernamen.
  2. Mit Zuordnung bestimmen Sie den Elternordner und damit die Position im Content Tree.
  3. Das Content-Template steuert die Darstellung der untergeordneten Seiten, sofern diese den Wert vom Parent erben.
  4. Mit den Leserechten begrenzen Sie, welche Benutzergruppen den Ordner und seine Inhalte sehen duerfen.
  5. Speichern Sie die Aenderung mit dem Button im unteren Formularbereich. Das Schliessen-Symbol verwirft noch nicht gespeicherte Eingaben.
Eine geaenderte Zuordnung verschiebt den Ordner mitsamt seiner darunterliegenden Struktur.
