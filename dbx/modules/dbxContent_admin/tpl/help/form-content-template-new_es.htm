Crear una nueva plantilla de contenido

  1. Introduzca un nombre de archivo que tiene c- Empieza.
  2. Después de eso, use sólo letras, números, hyphens y subrayas.
  3. Seleccione Creación. El contenido básico se genera en la carpeta de plantilla del módulo de contenido.
  4. A continuación, abrir la nueva plantilla en el editor y ajustar las áreas de contenido previstas.
El nombre se introduce sin extensión de archivo. Una plantilla existente del mismo nombre no debe ser escrita involuntariamente.
