What is this module for?

myLKW is an example module for managing vehicles in the vehicle fleet. It shows how technical data in dbXapp can be clearly maintained.

What can you do with it?

  • Listing vehicles and viewing details
  • Catching new vehicles
  • Change of Day and Set Date for Dispositions
  • Use evaluations and lists for the fleet
Example: Trigger the change of day in the morning, then check the current vehicle list and add a new vehicle if necessary.
