dbxForm in einem Arbeitsgang

Dieser Einstieg führt vom DD/FD-Vertrag bis zum geprüften Speichern. Für Spezialfälle bleibt das ausführliche Gesamtdokument erhalten.

Wann dbxForm passt

  • Datensätze anlegen oder bearbeiten
  • validierte Filter- und Konfigurationsmasken
  • mehrstufige oder per AJAX aktualisierte Formulare

Der verbindliche Ablauf

  1. DD und sprachabhängige FD definieren.
  2. dbxForm initialisieren und Daten, RID sowie Action setzen.
  3. Felder vor der Submit-Prüfung hinzufügen.
  4. submit() und errors() auswerten.
  5. über save_post() speichern und immer mit run() rendern.
$form = dbx()->get_system_obj('dbxForm');
$form->init('customer-edit', 'customer-edit');
$form->_dd = 'crm|customer';
$form->_fd = 'crm|customer-form';
$form->_data = $data;
$form->_rid = $rid;
$form->add_flds();

if ($form->submit() && !$form->errors()) {
    $form->save_post($form->_dd, $rid ?: 'new');
}

return $form->run();
