Starting workflow

This page shows the goal of an active workflow definition. With Starting workflow A new, independent pass is created.

Check the objective and description Starting the workflow New instance with definition snapshot → First Applicable Step

Before take-off

  • Check whether the goal and description fit the desired process.
  • Every click on Starting Creates a new instance. For an existing run use instead its resume link.
  • For specialized workflows, a data set can already be preselected.

If the workflow is unknown or deactivated in the administration, no replacement or demo process is started. An administrator must define in dbxWorkflow_admin check.
