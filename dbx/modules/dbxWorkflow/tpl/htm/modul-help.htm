Wofür ist dieses Modul?

dbxWorkflow führt die aktiven, in dbxWorkflow_admin definierten Abläufe aus. Jeder Start erzeugt einen eigenen Durchlauf mit festem Definitionsstand, Werten, Fortschritt und Schritt-Historie.

Workflow starten → Pflichtangaben bearbeiten → Entscheidungen und Prüfungen durchlaufen → Zusammenfassung kontrollieren → Finish ausführen

Bei der Nutzung

  • Jeder Start erzeugt eine neue Instanz; einen vorhandenen Vorgang über dessen Fortsetzen-Link öffnen.
  • Gesperrte Schritte warten auf eine Voraussetzung.
  • Optionale Schritte können bewusst übersprungen werden.
  • Fachmodul-Schritte zuerst im geöffneten Modul speichern und danach im Workflow bestätigen.
  • Externe Aktionen vor Neustart oder Wiederholung beim Provider kontrollieren.

Unbekannte oder deaktivierte Workflow Keys werden nicht durch einen Demo-Workflow ersetzt.
