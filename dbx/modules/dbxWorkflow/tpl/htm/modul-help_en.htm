What is this module for?

dbxWorkflow lead the active, in dbxWorkflow_admin defined processes. Each start generates its own pass with a fixed definition status, values, progress and step history.

Start workflow → Process mandatory information → Go through decisions and audits → Control summary → Complete the finish

When used

  • Each start generates a new instance; open an existing process via its resume link.
  • Locked steps await a prerequisite.
  • Optional steps can be deliberately skipped.
  • Save subject module steps first in the open module and then confirm them in the workflow.
  • Control external actions before restart or repetition at the provider.

Unknown or deactivated workflow keys are not replaced by a demo workflow.
