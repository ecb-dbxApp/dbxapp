Shop management

In the shop management you maintain items, prices, orders, payments, shipping, media and external sales channels.

Important procedure

  1. First, check which dataset and, if applicable, which channel you are editing.
  2. Maintain basic data, visibility, prices and assignments in the designated areas.
  3. Save the action in the form bar and control the subsequent status message.
  4. For orders, you check especially payment, shipping and the option for customer notifications before changing statuses.
Deletion, export and status actions can trigger follow-up actions. Read a confirmation displayed completely before proceeding.
