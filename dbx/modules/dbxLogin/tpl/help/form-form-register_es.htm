Crear una cuenta nueva

  1. Seleccione un nombre de usuario único y escriba su nombre y una dirección de correo electrónico accesible.
  2. Introduzca la misma nueva contraseña en ambos campos de contraseña. No se almacenan diferentes entradas.
  3. Seleccione el idioma para su cuenta y inicie el registro.
  4. Después de eso, abra el correo electrónico de confirmación y siga el enlace. Sólo la confirmación desbloquea la cuenta para el registro normal.
Si no llega ningún mensaje, compruebe la carpeta de spam. Después de un intento de inicio de sesión, el enlace de confirmación se puede solicitar de nuevo.
