Bestaetigungslink erneut senden

Das Passwort wurde akzeptiert, aber die zum Konto gehoerende E-Mail-Adresse ist noch nicht bestaetigt.

  1. Pruefen Sie, ob die angezeigte E-Mail-Adresse zu Ihrem Konto gehoert.
  2. Waehlen Sie Bestaetigungslink erneut senden. Dadurch wird ein neuer, zeitlich begrenzter Link erzeugt; ein aelterer Link kann danach ungueltig sein.
  3. Oeffnen Sie die neue E-Mail und bestaetigen Sie das Konto. Anschliessend koennen Sie sich normal anmelden.
Fordern Sie nur dann einen neuen Link an, wenn Sie Zugriff auf das angezeigte Postfach haben.
