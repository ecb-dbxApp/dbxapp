Create a new account

  1. Select a unique username and enter your name and a reachable email address.
  2. Enter the same new password in both password fields. Different inputs are not stored.
  3. Select the language for your account and start registration.
  4. After that, open the confirmation email and follow the link. Only the confirmation unlocks the account for the normal registration.
If no message arrives, check the spam folder. After a login attempt, the confirmation link can be requested again.
