Shop im Frontend

Die Shop-Formulare fuehren von der Artikelauswahl ueber Warenkorb und Kundendaten bis zum Abschluss einer Bestellung.

  1. Pruefen Sie Artikel, Variante, Menge und angezeigten Preis.
  2. Kontrollieren Sie im Warenkorb alle Positionen und Versandkosten.
  3. Geben Sie Rechnungs- und Lieferdaten vollstaendig ein und waehlen Sie die angebotene Zahlungs- und Versandart.
  4. Pruefen Sie die Zusammenfassung, bevor Sie die Bestellung verbindlich absenden.
Eine Bestellung gilt erst dann als uebermittelt, wenn eine eindeutige Abschluss- oder Bestaetigungsmeldung angezeigt wird.
