Wofür ist dieses Modul?

dbxHelp zeigt kontextbezogene Hilfetexte in Fenstern und Dialogen. So finden Sie Erklärungen genau dort, wo Sie gerade arbeiten.

Was können Sie damit tun?

  • Hilfe zu einem Bereich per Fragezeichen-Button öffnen
  • Kurzanleitungen und Tipps im Dialog lesen
  • Ohne die laufende Arbeit den Kontext verlassen
Tipp: Wenn Sie unsicher sind, klicken Sie auf Hilfe in der Modulleiste — die Erklärung bezieht sich auf den aktuellen Bereich.
