Purpose

DB Sync manages records directly in tables (read, paste, edit, delete) based on the DD structure.

Relationship DD ↔ DB

DD Sync (structure) → DB Sync (data) rows/content tables/fields

Procedure

  1. Select table from DD list.
  2. Data paginates viewing, filtering, sorting.
  3. Edit line or create new line.
  4. CSV Import/Export for mass changes.

Opportunities

  • Table data paginates viewing and filtering.
  • CSV Import/Export per table.
  • Individual tables backup/restore.
  • Trace history per record (when active).
Example: test data set in workflowDefinition Correct → DB Sync → Row Edit → Adjust JSON field → Save → Workflow admin shows updated definition.
