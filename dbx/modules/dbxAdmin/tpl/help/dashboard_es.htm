Propósito

El administrador dashboard paquetes sistema statuses, bases de datos, módulos y actividades recientes.

Procedimiento

  1. Verificar figuras clave arriba (conexiones DB, tablas, módulos).
  2. Saltar directamente a áreas de administración frecuentes a través de las tarjetas de acción.
  3. Utilice áreas de rendimiento y actividad para cuellos de botella.
Dashboard → Seleccionar área → Detalle admin → Ejecutar acción → Revisar el panel
Ejemplo: High Trace Number → Open Trace → Filtrar la tabla afectada → Ver historial.
