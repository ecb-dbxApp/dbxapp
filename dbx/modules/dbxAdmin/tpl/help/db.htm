Zweck

DB Sync verwaltet Datensätze direkt in Tabellen (Lesen, Einfügen, Bearbeiten, Löschen) — auf Basis der DD-Struktur.

Beziehung DD ↔ DB

DD Sync (Struktur) → DB Sync (Daten) Tabellen/Felder Zeilen/Inhalte

Vorgehensweise

  1. Tabelle aus DD-Liste wählen.
  2. Daten paginiert anzeigen, filtern, sortieren.
  3. Zeile bearbeiten oder neue Zeile anlegen.
  4. CSV Import/Export bei Massenänderungen.

Möglichkeiten

  • Tabellendaten paginiert anzeigen und filtern.
  • CSV Import/Export pro Tabelle.
  • Einzelne Tabellen backup/restore.
  • Trace-Historie pro Datensatz (wenn aktiv).
Beispiel: Testdatensatz in workflowDefinition korrigieren → DB Sync → Zeile editieren → JSON-Feld anpassen → Speichern → Workflow-Admin zeigt aktualisierte Definition.
