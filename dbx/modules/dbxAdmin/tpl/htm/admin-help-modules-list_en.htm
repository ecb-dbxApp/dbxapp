Purpose

Overview of all installed modules. Module images for the interpreter are under files/mod (file name): {modul}_…) and are automatically recognized there.

Opportunities

  • Config Edit module configuration in the window.
  • Installer — is displayed if the module uses a PHP install-Run provided.
  • Assistance — automatically recognized description, DD list and default call.
  • Preview — Test standard module call in openWin.
  • Access View groups and edit them by form.
Note: DD names and run actions are derived from module PHP and the folder dd/ No manual registry is required.
