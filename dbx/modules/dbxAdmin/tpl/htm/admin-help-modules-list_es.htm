Propósito

Vista general de todos los módulos instalados. Las imágenes del módulo para el intérprete están bajo files/mod (Nombre del fichero): {modul}_…) y se reconocen automáticamente allí.

Oportunidades

  • Config Editar configuración del módulo en la ventana.
  • Installer — se muestra si el módulo utiliza un PHP install- Listo.
  • Asistencia — descripción reconocida automáticamente, lista DD y llamada predeterminada.
  • Vista previa — Prueba de la llamada de módulo estándar en openWin.
  • Acceso Ver grupos y editarlos por forma.
Nota: Los nombres de DD y las acciones de ejecución se derivan del módulo PHP y la carpeta dd/ No se requiere registro manual.
