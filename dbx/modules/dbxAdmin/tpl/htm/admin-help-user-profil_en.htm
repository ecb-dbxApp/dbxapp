My profile

Here you maintain your personal data, contact details and surface settings.

  • Storage transfers the form values to your user account.
  • Reload rejects unstored changes and loads the current status from the server.
  • Avatar and image can be uploaded separately on the right.

Fields

  • Personal data: Name, addition, e-mail
  • Communication: Telephone, mobile
  • Address: Road, postal code, town, country
  • Surface: Language, design, colour
