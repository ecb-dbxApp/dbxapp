Zweck

DD Sync vergleicht DataDictionary-Dateien (*.dd.php) mit der physischen Datenbankstruktur.

Sync-Ablauf

DD-Datei (Quelle) DB-Tabelle (Ziel) │ │ ├─ Feld fehlt in DB ──► ALTER / CREATE ├─ Feld fehlt in DD ──► Warnung / Review └─ Apply schrittweise ─► finished

Vorgehensweise

  1. Modul/DD in der Liste wählen.
  2. Sync-Plan prüfen (fehlende Felder, Indizes, Typen).
  3. Apply schrittweise ausführen — kein blindes Reset in Produktion.
  4. Danach DB Sync testen (Datenzugriff).

Möglichkeiten

  • Einzelnes DD oder alle Module synchronisieren.
  • Feldvergleich (separater Menüpunkt) für Detail-Diff.
  • Backup/Restore über DD-Menü (vor strukturellen Änderungen).
Beispiel: Neues Feld reply_status in contactRequest.dd.php → DD Sync zeigt pending Feld → Apply → Spalte in MySQL angelegt.
