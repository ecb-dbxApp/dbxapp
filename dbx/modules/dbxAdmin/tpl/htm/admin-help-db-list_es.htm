Propósito

DB Sync gestiona los registros directamente en tablas (read, paste, edit, delete) basadas en la estructura DD.

Relación DD ↔ DB

DD Sync (estructura) → DB Sync (data) filas/contenidos tablas/campos

Procedimiento

  1. Seleccione la tabla de la lista DD.
  2. Data paginates visualización, filtrado, clasificación.
  3. Editar línea o crear nueva línea.
  4. CSV Importación/Exporte para cambios masivos.

Oportunidades

  • Tabla datos paginates visualización y filtrado.
  • CSV Importación/Exporte por tabla.
  • Tablas individuales de respaldo / restauración.
  • Historial de traza por registro (cuando está activo).
Ejemplo: data set in workflowDefinition Correcto → DB Sync → Row Edit → Ajuste campo JSON → Guardar → Workflow admin muestra la definición actualizada.
