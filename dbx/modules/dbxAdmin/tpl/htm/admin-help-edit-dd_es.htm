Propósito

DD Editor mantiene metadatos de mesa y definiciones de campo en dd/*.dd.php.

Procedimiento

  1. Mesa abierta + campos en el editor.
  2. Tipo de campo, reglas, ajuste índice.
  3. Guardar el orden por arrastrar.
  4. Entonces ejecute DD Sync.
DD Editor → Agregar campo → Guardar → Aplicación de sincronización DD
