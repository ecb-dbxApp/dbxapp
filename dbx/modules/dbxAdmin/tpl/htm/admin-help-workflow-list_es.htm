¿Para qué es esta visión general?

Aquí usted administra las definiciones que el módulo dbxWorkflow más tarde. dbxWorkflow_admin especifica el objetivo, pasos, pruebas y conexiones de módulos opcionales; dbxWorkflow genera una instancia separada para cada inicio.

Definición en dbxWorkflow_admin Activar y probar → Comenzando en dbxWorkflow Instalación con instantánea de definición → Pasos de procesamiento Examinar y completar

Procedimiento típico

  1. Nuevo flujo de trabajo: Establecer el objetivo y la clave de flujo de trabajo estable.
  2. Pasos: Poner insumos, acciones, pruebas y decisiones en el orden correcto.
  3. Prueba: Primero guardar, controlar y luego activar la definición.
  4. Empezando: Sobre la acción inicial un nuevo paso dbxWorkflow abierto.
  5. Supervisión: Corridas continuas y cerradas bajo Casos de flujo de trabajo Mira.

Importante

  • Sólo se pueden reiniciar definiciones activas.
  • Una clave de flujo de trabajo desconocida o desactivada no es reemplazada por una caducidad de demostración.
  • Al inicio, la instancia guarda una instantánea. Por lo tanto, los cambios posteriores sólo se aplican a nuevas carreras.
  • Los ejemplos incluidos se crean una vez durante la instalación y se pueden editar como definiciones normales.
Ejemplo: project_offer Activar en la lista → Empezando → dbxWorkflow Crea una nueva instancia y muestra el primer paso aplicable.
