Inicio del flujo de trabajo

Esta página muestra el objetivo de una definición de flujo de trabajo activo. Con Inicio del flujo de trabajo Se crea un nuevo pase independiente.

Compruebe el objetivo y la descripción Inicio del flujo de trabajo Nueva instancia con instantánea de definición → Primer paso aplicable

Antes del despegue

  • Compruebe si la meta y la descripción encajan en el proceso deseado.
  • Cada clic en Empezando Crea una nueva instancia. Para un uso de ejecución existente en lugar de su enlace de reanudación.
  • Para los flujos de trabajo especializados, un conjunto de datos ya puede ser preseleccionado.

Si el flujo de trabajo es desconocido o desactivado en la administración, no se inicia ningún proceso de sustitución o demo. Un administrador debe definir en dbxWorkflow_admin Mira.
