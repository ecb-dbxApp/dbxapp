Workflow starten

Diese Seite zeigt das Ziel einer aktiven Workflow-Definition. Mit Workflow starten wird ein neuer, unabhängiger Durchlauf angelegt.

Ziel und Beschreibung prüfen → Workflow starten → neue Instanz mit Definitions-Snapshot → erster anwendbarer Schritt

Vor dem Start

  • Prüfen, ob Ziel und Beschreibung zum gewünschten Vorgang passen.
  • Jeder Klick auf Starten erzeugt eine neue Instanz. Für einen vorhandenen Durchlauf stattdessen dessen Fortsetzen-Link verwenden.
  • Bei fachgebundenen Workflows kann bereits ein Datensatz vorgewählt sein.

Ist der Workflow unbekannt oder in der Verwaltung deaktiviert, wird kein Ersatz- oder Demo-Ablauf gestartet. Ein Administrator muss die Definition in dbxWorkflow_admin prüfen.
