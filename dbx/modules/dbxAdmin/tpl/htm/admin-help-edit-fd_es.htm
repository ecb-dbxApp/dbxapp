Propósito

FD editor define campos de formularios ()fd/*.fd.php) dbxForm/dbxReport.

Oportunidades

  • Etiquetas, tipo TPL, validación, mantener opciones.
  • Genera automáticamente FD de campos DD.
  • Versiones de idiomas _en.fd.php y _es.fd.php mantener los mismos nombres de campo y textos de la UI traducidos.
  • $messages['save_success'] y $messages['save_error'] son de dbxForm y dbxReport automáticamente usado.
Ejemplo: Nuevo campo de filtro de informe → Crear FD → Informe create_selection_fields() uso.
