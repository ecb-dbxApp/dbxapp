Propósito

DD Sync compara los archivos DataDictionary ()*.dd.phpcon la estructura de bases de datos físicas.

Sincronización

DD file (source) DB table (target) . - Campo desaparecido en DB - ► ALTER / CREATE - Campo desaparecido en DD - ► Advertencia / revisión - Aplicar paso a paso -► terminado

Procedimiento

  1. Seleccione el módulo/DD en la lista.
  2. Verifique el plan de sincronización (campos perdidos, índices, tipos).
  3. Aplicar Realizar gradualmente, sin reiniciar ciegamente en la producción.
  4. Luego prueba DB Sync (acceso de datos).

Oportunidades

  • Sincronizar DD individual o todos los módulos.
  • Comparación de campo (objeto de menú separado) para el desvío de detalles.
  • Backup/Restore vía DD menu (antes de cambios estructurales).
Ejemplo: Nuevo campo reply_status dentro contactRequest.dd.php → DD Sync muestra campo pendiente → Aplicar → columna creada en MySQL.
