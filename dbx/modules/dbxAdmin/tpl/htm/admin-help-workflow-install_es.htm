¿Qué está instalado?

La instalación compara los cuatro DD de flujo de trabajo con la base de datos y crea definiciones de demo desaparecidas y vinculantes estándar.

Installer → workflowDefinition synchronize → flujo de trabajoSincronización de la posición → workflowStep synchronize → flujo de trabajoModulesBind sincroniza → Faltando ejemplos y agregando enlaces

¿Cuándo ejecutar?

  • durante la instalación inicial de: dbxWorkflow;
  • después de una actualización del flujo de trabajo DDs;
  • si las tablas o los ejemplos incluidos siguen desaparecidos.

Las definiciones existentes siguen siendo: La instalación solo complementa los flujos de trabajo demo si su clave de flujo de trabajo aún no está disponible. In dbxWorkflow_admin Los procesos procesados no son sobrescritos por las especificaciones PHP de nuevo.

Después de esta actualización: Instala una vez para que workflowInstance.definition_json para nuevas instantáneas de definición.
