Was wird installiert?

Die Installation gleicht die vier Workflow-DDs mit der Datenbank ab und legt fehlende Demo-Definitionen sowie Standard-Bindings an.

Install → workflowDefinition synchronisieren → workflowInstance synchronisieren → workflowStep synchronisieren → workflowModuleBind synchronisieren → fehlende Beispiele und Bindings ergänzen

Wann ausführen?

  • bei der Erstinstallation von dbxWorkflow;
  • nach einem Update der Workflow-DDs;
  • wenn Tabellen oder mitgelieferte Beispiele noch fehlen.

Bestehende Definitionen bleiben erhalten: Die Installation ergänzt Demo-Workflows nur, wenn deren Workflow Key noch nicht vorhanden ist. In dbxWorkflow_admin bearbeitete Abläufe werden nicht wieder durch PHP-Vorgaben überschrieben.

Nach diesem Update: Install einmal ausführen, damit workflowInstance.definition_json für neue Definitions-Snapshots angelegt wird.
