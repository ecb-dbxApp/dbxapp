Was zeigt diese Übersicht?

Jeder Start in dbxWorkflow erzeugt eine eigene Instanz. Die Liste zeigt Workflow Key, Ziel, Status, aktuellen Schritt, Fortschritt und die letzte Meldung.

Status verstehen

running → paused → running → finished └──────────────→ canceled → error
  • Läuft: der nächste anwendbare Schritt kann bearbeitet werden.
  • Angehalten: Werte bleiben erhalten; der Durchlauf kann fortgesetzt werden.
  • Abgebrochen: keine weitere Bearbeitung ohne bewussten Neustart.
  • Fertig: alle Pflichtschritte und die Finish-Logik waren erfolgreich.
  • Fehler: Meldung und Fachmodul prüfen.

Fehler suchen

  1. Instanz über die Aktion öffnen.
  2. Letzte Meldung und aktuellen Schritt lesen.
  3. Bei gesperrten Schritten Voraussetzung und erwarteten Ergebniswert prüfen.
  4. Bei Modulaktionen den Fachdatensatz und das verwendete Binding kontrollieren.
  5. Bei externen Aktionen vor einem Neustart zuerst den Providerstatus prüfen.

Definitionsstand: Neue Instanzen speichern beim Start einen Snapshot. Änderungen in dbxWorkflow_admin verändern daher keine bereits gestarteten Abläufe. Ältere Instanzen ohne Snapshot verwenden aus Kompatibilitätsgründen weiterhin die aktuelle Definition.
