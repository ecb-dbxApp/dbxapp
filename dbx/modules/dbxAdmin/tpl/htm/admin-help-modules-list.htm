Zweck

Uebersicht aller installierten Module. Modul-Bilder fuer den Interpreter liegen unter files/mod (Dateiname: {modul}_…) und werden dort automatisch erkannt.

Moeglichkeiten

  • Config — Modul-Konfiguration im Fenster bearbeiten.
  • Install — wird angezeigt, wenn das Modul per PHP einen install-Run bereitstellt.
  • Hilfe — automatisch erkannte Beschreibung, DD-Liste und Standardaufruf.
  • Vorschau — Standard-Modulaufruf in openWin testen.
  • Zugriff — Gruppen anzeigen und per Formular bearbeiten.
Hinweis: DD-Namen und Run-Aktionen werden aus Modul-PHP und dem Ordner dd/ erkannt — keine manuelle Registry noetig.
