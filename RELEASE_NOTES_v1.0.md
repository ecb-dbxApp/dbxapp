# dbXapp 1.0 Release Notes

Version 1.0 fasst den aktuellen lokalen Entwicklungsstand als neue
Referenzversion zusammen.

## Schwerpunkt

- Doxygen-Dokumentation mit doxygen-awesome-css aktualisiert.
- dbxTPL, dbxDB, DD/FD, dbxForm, dbxReport, Module, CMS, dbxKi,
  JavaScript-Libs und verbindliche KI-Regeln umfassender dokumentiert.
- dbxKi-Dokumentation um visuelle CMS-Nutzung, direkten Zugriff fuer
  Codex/Cursor und ZIP-Bundle-Workflow erweitert.
- Font Awesome entfernt und vorhandene Verwendungen auf Bootstrap Icons
  umgestellt.
- Tabulator-Auslieferung auf die benoetigten Runtime-Dateien reduziert.
- Lokaler Stand gilt als Wahrheit fuer die Version 1.0: entfernte Dateien
  sind nicht mehr Bestandteil der Version.

## Hinweise

- `C:/xampp/htdocs/dbxapp-docs` ist generierte Doxygen-Ausgabe.
- Die Dokumentationsquellen liegen im Repository als Markdown-Dateien und
  werden ueber `Doxyfile` generiert.
